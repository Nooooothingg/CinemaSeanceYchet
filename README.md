# Учёт киносеансов

## Описание системы
Система ведёт учёт киносеансов.

## Цели системы
*   Дать пользователям возможность просмотра киносеансов в их городе с возможностью перехода на сайт кинотеатра для дальнейшей покупки билетов.
*   Предоставить администраторам кинотеатров площадку для размещения своих сеансов.

## Пользователи системы
1.  Клиенты
2.  Администраторы кинотеатров
3.  Администратор системы

## Функциональные возможности

### Клиент
*   Просмотр общего списка сеансов в кинотеатрах.
*   Просмотр сеансов на конкретный фильм.
*   Просмотр сеансов на конкретный день.
*   Просмотр сеансов в конкретном кинотеатре.

### Администратор кинотеатра
*   Установка списка сеансов в своём кинотеатре с указанием времени и стоимости билетов.
*   Добавление фильмов в базу данных системы.

### Администратор системы
*   Выполнение всех действий, доступных администраторам кинотеатров.
*   Регистрация администраторов кинотеатров.


*   **Архитектура:** Классическая трёхуровневая.
*   **Способ реализации:** Консольное приложение.
